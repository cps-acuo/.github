# Acuo

Welcome to Acuo's GitHub organization. We build solutions that streamline package bookings and enhance customer experiences.

## Our Solutions

### Operations
A fully featured backend for managing package bookings and related activities. The core application is a model-driven Power App that provides comprehensive tools for operations management.

### Web Bookings
A booking form that provides visitors with an intuitive, interactive booking experience. Our web interface makes it easy for customers to explore and book packages online.

### WordPress Plugin
A plugin that enables WordPress designers to create and manage content supporting package offerings and bookings from the Power App. Seamlessly integrate your booking system with your WordPress site.
